# LINE 聊天摘要工具（Codex 版）

版本：2.5.3（2026-09-24）  
平台：Windows 10／11 x64  
介面：HTML + 本機 Node.js 服務  
聊天來源：LINE Windows 桌面版本機加密資料庫（唯讀）  
摘要：Codex CLI，使用已登入的 ChatGPT/Codex 帳號

## 功能

- 從 LINE 本機同步資料庫列出群組與聊天室；不必開啟聊天室視窗，不操作滑鼠，也不點選「儲存聊天」。
- 讀取前由使用者勾選確認；工具只讀取 LINE 程序記憶體中的資料庫解鎖資訊，並以唯讀模式開啟 `.edb` 資料庫。解鎖資訊不寫入檔案或日誌。
- 使用雙月曆選擇日期區間，支援近 7 天、近 30 天、點選起訖日期及按住拖曳。
- 摘要直接顯示在畫面右側；每次最多讀取 20,000 則訊息。只分析文字，圖片、語音、檔案等會以類型標記表示。
- 摘要前遮蔽常見電子郵件與臺灣手機號碼；本機日誌不保存聊天文字、群組名稱、解鎖資訊或摘要內容。
- 不輸出聊天 TXT 或摘要檔。仍可選擇匯入 LINE 手動匯出的 TXT 作為備用來源；匯入檔原始檔不會被修改，工具只建立暫存副本並於處理後清理。

## 前置條件

1. Windows 10／11 x64，LINE Windows 桌面版已登入，且聊天資料已同步到這台電腦。
2. Node.js 22 或更新版本。使用一鍵安裝程式時，若找不到相容的 Node.js，安裝程式會下載 Node.js 22 LTS 免安裝執行環境並放在程式資料夾，不修改系統 PATH。
3. Codex CLI 已安裝，並在同一個 Windows 帳號登入。

摘要文字會透過已登入的 Codex CLI 送交 Codex 模型處理。使用前請確認選取的聊天內容適合交由該服務處理。

## 啟動與操作

### 第一次安裝

1. 執行 `LineChatSummary-Codex.exe`。首次使用時，它會安裝本工具；若找不到 Node.js 22 或更新版本，會從 Node.js 官方網站下載 Windows x64 壓縮包，驗證 SHA-256 後放到目前使用者的程式資料夾。
2. 安裝程式不安裝 LINE 或 Codex CLI，也不修改它們的登入資料。使用者需先自行安裝並登入這兩項程式。
3. 安裝完成後會建立開始功能表捷徑並開啟工具。之後再次執行同一個 `LineChatSummary-Codex.exe` 會直接開啟已安裝的工具，不會重複安裝。首次下載 Node.js 時需要網路；產生摘要時也需要連線到 Codex 服務。

### 直接啟動

1. 開啟並登入 LINE Windows 桌面版；不必維持聊天室視窗開啟。
2. 首次執行 `LineChatSummary-Codex.exe` 安裝；安裝後可再次執行同一個 `LineChatSummary-Codex.exe`，或從開始功能表開啟工具。主程式安裝在 `%LOCALAPPDATA%\Programs\LineChatSummary`，介面與資料庫元件會解壓到 `%LOCALAPPDATA%\LineChatSummary\web`。
3. 勾選本機 LINE 記憶體讀取說明，按「載入群組」。首次掃描可能需要一段時間；載入後可按「重新載入」更新清單。
4. 選擇群組與日期區間，按「產生聊天大意」。完成後摘要直接顯示在畫面右側，可複製摘要文字。
5. 若本機資料庫無法讀取，可按「匯入 TXT 備用」選擇 LINE 手動儲存的聊天記錄。

HTML 來源為 `line-chat-summary-preview.html`。直接開啟 HTML 只能預覽畫面；讀取 LINE 與呼叫 Codex 必須透過 EXE 啟動的本機服務。

## 日誌與資料處理

- 日誌位置：`%LOCALAPPDATA%\LineChatSummary\logs`
- 日誌記錄階段、耗時、訊息數、字元數、LINE 版本及不含聊天資料的錯誤摘要。
- LINE 資料庫以 SQLite 唯讀連線開啟，並啟用 query-only 模式；工具不更新 LINE 資料庫。
- 聊天內容只在本次篩選與摘要過程中由本機服務暫存於記憶體，再傳給 Codex CLI；本機不建立聊天 TXT。摘要臨時輸出檔處理完會清除。
- 遮蔽僅涵蓋常見 Email 與臺灣手機格式，不是完整匿名化。

## 已知限制

- LINE 沒有提供本工具使用的官方群組聊天歷史 API。這個讀取方式依據公開的 Windows 本機資料格式與加密方式研究，非 LINE 官方介面；LINE 更新可能變更資料表、資料庫位置、加密方式或記憶體配置。
- 群組清單與聊天歷史只包含 LINE 已同步到本機的資料；尚未同步到電腦的舊訊息不會出現在摘要中。
- 目前採用 wxSQLite3 相容的 `aes128cbc` cipher。LINE 版本或資料庫格式不符時，工具會在日誌留下階段與錯誤類別，請勿把解鎖候選值或聊天內容貼到日誌中。
- 訊息數超過 20,000 則時，請縮短日期範圍。LINE 的圖片、語音及檔案內容不會被辨識。
- 本工具尚未在你的 LINE 實際資料庫完成端到端驗證；第一次載入若失敗，請保留 `%LOCALAPPDATA%\LineChatSummary\logs` 下當日 `web-*.log` 供修正。

## 故障排除

| 現象 | 檢查方式 |
|---|---|
| 找不到 LINE 資料庫 | 確認 LINE 已登入、使用同一 Windows 帳號，並檢查 `%LOCALAPPDATA%\LINE\Data\db` 是否有 `.edb` 檔。 |
| 無法讀取 LINE 程序記憶體 | 確認 LINE 與工具在相同 Windows 使用者及相同權限下執行，再按「重新載入」。 |
| 找到資料庫但無法解鎖 | 按「重新載入」重新掃描；若近期更新過 LINE，可能需要重新確認資料庫 cipher 或金鑰格式。 |
| 群組清單空白 | 確認該群組已在 LINE 桌面版同步；重開 LINE 登入後再載入。 |
| 範圍內沒有訊息 | 調整日期範圍；本工具只查目前已同步至本機的訊息。 |
| Codex 無法摘要 | 確認 Codex CLI 已安裝、同一帳號已登入，並可連線至 Codex 服務。 |

## 回復方式

若 2.5.3 的本機資料庫讀取失敗，可暫時改用舊版 `LineChatSummary-2.4.7.zip` 內的 EXE，並手動匯入 LINE TXT。舊版依賴 LINE 視窗自動化，沒有本版的本機資料庫讀取功能。

## 維護與重新建置

維護套件包含 `Launcher.cs`、`SetupLauncher.cs`、`server.js`、`line-db.js`、PowerShell 資料庫掃描程式、HTML、資料庫原生元件壓縮檔與 `Build.ps1`。重新建置需要 Windows .NET Framework C# 編譯器。`Build.ps1` 會輸出唯一的 `LineChatSummary-Codex.exe`；它內含主程式，首次安裝後可重複用來啟動工具。

在此資料夾執行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

第三方元件與授權請見 `THIRD-PARTY-NOTICES.md`。
